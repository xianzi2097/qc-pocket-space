# QC-Studio / 青橙 Studio

少儿编程学习平台 — 专为培训机构和小型课堂打造的开源解决方案。

集成 Scratch 4.0 在线编程 + VitePress 课程文档 + 课堂管理系统。老师可创建课程、注册学生、查看作品与笔记；学生无需复杂注册即可上课。

技术栈：FastAPI + React + Tailwind CSS + SQLite，纯内网部署，解压即用。

## 🚀 快速开始

```bash
# 1. 克隆项目
git clone git@gitee.com:Arin-Cabin/qc-pocket-space.git

# 2. 运行启动器
双击 qx-launcher/启动启动器.bat
```

> 首次启动自动创建管理员（admin / 111111），请立即修改密码。
