## 这是什么

少儿编程教学平台的**全新后端**。与 V1（`../backend/`）并排存在、互不干扰：

| | V1（在跑） | V2（开发中） |
|---|---|---|
| 端口 | 8000 | 8001 |
| 数据 | `data/qingcheng.db` + 散落的 JSON | `data_v2/codenova_v2.db`（结构化数据全入库，与 data/ **平级**） |
| 接口 | 91 个（动词式 URL） | 78 个（RESTful + 统一信封） |
| 状态 | **不动，继续对外服务** | 本月开发完 → 前端一起改 → 一次性切换 |

## 一次请求的流转

```
POST /api/auth/login
   → main.py 路由匹配
   → envelope.py 参数校验（缺参就地返回 1001）
   → routers/auth.py 四步：解析参数 → 鉴权 → 业务 → return ok(...)
        ├ security.py 限流 / 验密码 / 发 token
        ├ db.py       开数据库会话
        └ models.py   操作 accounts、auth_sessions 表
   → envelope.py 包成 {"code":0,...}（出错则 ApiError → 兜底处理器）
   → 客户端
```

### M2 资产与文件树做了什么（2026-10-08）

- **范围**：规范 §3.4 资产 13 接口 + §3.5 文件树七动作，三件套落地——`routers/assets.py`（接口）、`filetree.py`（service）、`publish.py`（发布队列）。**D16 合表 + D17 接口合一在本阶段兑现**：一张 `assets` 表、一个 `/api/assets` 前缀、文件树一个挂载点，`shelf/category` 词汇死亡、全域只叫 `bucket`。
- **新物种（M1 没有的三个概念）**：① **库+盘双写**（建资产 = 行 +1 且磁盘建 id 目录，删资产四联动：行删/ trash 快照 / 磁盘移回收站 / `file_order` 保留）；② **后台单线程队列**（C9 入队即返回，worker 串行跑 vitepress——V1 build.py 全平移，产物按资产 id；测试 monkeypatch，真实渲染 M4 收口）；③ **流式打包**（E6 单文件直发 / 目录实时 zip、发完即弃）。
- **业务规则**：族守卫 5 处（lessons/publish 仅课程族、zip 仅资料族，违反 404）；重名按 owner **跨族全局拦**（5001/6001）；F3 自动建中间层目录（D14③ 魔改 Scratch 直用）；F5 账随货走（目录改名 → `file_order` 前缀批量更新、同名幂等）；F7 全量重写顺序（幂等）；F2 inline/attachment 按扩展名（D15 按钮露出归前端）；bucket 跨族挪动允许（D17：课→资料归档）。
- **验证**：48 条验收单**先红后绿**（首跑 46 红 → 实现后 48 全绿），双断言盯"盘上真有/真没"；命名闸门逼出 `assets` 段登记（登记制生效）。全量 **167 用例绿**。

### M1b 班级域做了什么（2026-10-06）

- **范围**：规范 §3.3 的 8 个接口 + 1 个详情（`routers/classes.py`，9 个动作）。V1 的 `students/list` 与 `find-student` 合并为 `GET /api/students?q=`；改名不再联动 sessions 目录（V2 用 class_id 关联，V1 那个 404 隐患从根上消失）。
- **业务规则**：可见范围三档（teacher 见自己的班 / admin 全部 / 学生见所在班）；重名按老师隔离；删班 = 删行 + `trash` 快照，**成员关系保留**（恢复即复原）；加学生挂接或现场建号、重复入班 409、仅学生角色；移出只删关系不删号。学生个人上课日（`schedule_override`）已砍（2026-10-07：暂不用，等真需要再写回）。
- **验证**：31 条验收单先行（先红后绿）。实现一次拿下 30 绿，第 31 条抓到**我用错错误码**（学生不在班内该用通用 `1004`，我写了"班级不存在"`4004`）——语义错误也由测试兜住。另修一处**跨文件测试污染**：两个测试文件共用一个临时库，班级测试的 `t_dup`/`t_del` 与账号测试撞名 → 统一 `cls_` 前缀（52 处）。
