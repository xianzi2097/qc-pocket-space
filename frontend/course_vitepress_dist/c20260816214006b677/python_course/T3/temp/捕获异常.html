捕获异常 ​

一、try except 是什么 ​

在程序运行过程中，难免会遇到各种错误。为了避免程序因为一个小错误就整个崩溃，可以使用 try except 来捕获并处理这些错误，让程序继续向下运行。

二、基本语法 ​

python
try:
    # 可能会出错的代码
except 错误类型:
    # 出现该错误时执行的代码

你可以根据需要添加多个 except，也可以加上 finally：

python
try:
    num = int(input("请输入一个数字:"))
    print(10 / num)
except ValueError:
    print("输入的不是数字")
except ZeroDivisionError:
    print("不能除以 0")

在 Python 中，except 后面可以不写错误类型，例如：

python
try:
    x = 10 / 0
except:
    print("发生错误")

这种写法可以捕获所有错误，但不推荐滥用，因为会把所有问题都隐藏起来，不利于调试。

更推荐的写法是：

python
except Exception as e:
    print("发生错误:", e)

或者捕获特定错误：

python
except ValueError:
    print("输入错误")

三、常见的写法 ​

1. 捕获特定错误 ​

python
try:
    open("test.txt", "r")
except FileNotFoundError:
    print("文件不存在")

2. 捕获所有错误（不推荐滥用） ​

python
try:
    x = 10 / 0
except Exception as e:
    print("发生错误:", e)

3. 使用 finally ​

finally 的代码无论是否报错都会执行。

python
try:
    f = open("data.txt", "r")
except FileNotFoundError:
    print("文件未找到")
finally:
    print("结束操作")

四、常见异常类型表 ​

异常名称触发场景
ValueError类型转换失败，如 int("abc")
TypeError类型不匹配，如列表加整数
IndexError下标越界，如访问不存在的列表元素
KeyError字典中找不到对应 key
ZeroDivisionError除数为 0
FileNotFoundError打开的文件不存在
NameError使用了未定义的变量
ImportError导入模块失败
RuntimeError运行时发生的常规错误
Exception所有异常的基类

五、try / except / else / finally 的结构示意 ​

尝试：
    # 尝试做这些可能出错的事
除非 出现错误类型1:
    # 如果出现错误类型1，就这样处理
除非 出现错误类型2:
    # 如果出现错误类型2，就这样处理
否则：
    # 如果没有出现任何错误，就做这个
最终：
    # 不管有没有出错，最后都要做这个

解释：

  • “尝试” 对应 try，放可能出错的代码。
  • “除非” 对应 except，可以写多个分支处理不同的错误类型。
  • “否则” 对应 else，只有在 没有任何异常 的情况下才执行。
  • “最终” 对应 finally，无论是否出错一定执行。
