TXT 文件操作 ​

内存：

RAM = Random Access Memory（随机存取存储器）

是计算机中 CPU 直接可访问的存储区域，用来临时存储正在运行的程序和数据。

访问速度快，掉电不能保存

硬盘/SSD/Flash 是计算机的 持久存储设备，用来长期保存数据和程序。

读写速度慢，可以保存数据

一. 什么是 txt 文件 ​

  • txt 文件就是普通的文本文件，里面只包含字符，没有格式（不像 Word、Excel 这些文件）。
  • 扩展名一般是 .txt。
  • 可以用记事本、VS Code、Notepad++ 等软件打开。
  • 常用来存储：
    • 日志信息
    • 配置数据
    • 简单表格数据（每行一条，用空格或逗号分隔）

二. txt 文件的特点 ​

特点解释
简单只存字符，不存图片、公式等
可读性强可以直接打开看内容
跨平台Windows、Linux、Mac 都能用
大小灵活很小的文件也可以存，也可以存几百 MB（不过大文件读写要注意效率）

三. 在 Python 中操作 txt 文件 ​

Python 提供了内置函数 open() 来读写文件。基本操作可以用 IPO 模型理解：

  • I (Input) → 读取文件
  • P (Process) → 处理数据（统计、修改、过滤）
  • O (Output) → 保存或输出结果

1. 基本操作流程 ​

python
# 打开文件
f = open(r"C:\Users\弦子\Desktop\demo.txt", "w")

# 写入内容
f.write("Hello, Python!\n")
f.write("文件操作真好玩！")

# 关闭文件
f.close()
模式含义是否会新建是否清空原文件可否读
"r"只读❌❌✅
"w"写入✅✅❌
"a"追加✅❌❌
"r+"读写❌❌✅
"w+"读写（清空）✅✅✅

✅推荐写法：

python
with open("demo.txt", "w", encoding="utf-8") as f:
    f.write("安全写入方式\n")

2. 读取文件内容 ​

IMPORTANT

Python 在 读取文件或执行代码 时，默认用 GBK 编码（这是 Windows 中文系统的默认）。创建txt文件可能是 UTF-8格式的，这会导致不指定编码的时候，打开出现程序错误。

py
# -*- coding: utf-8 -*-
# 方式一：read()
with open("test.txt", "r", encoding="utf-8") as f:
    print(f.read())     # 一次性读完整个文件

# 方式二：readline()
with open("test.txt", "r",encoding="utf-8") as f:
    print(f.readline()) # 读一行
    print(f.readline()) # 再读一行

# 方式三：readlines()
with open("test.txt", "r",encoding="utf-8") as f:
    lines = f.readlines()  # 得到列表
    print(lines)

4. 练习题 ​

练习 1：写入和追加

题目：

  1. 创建一个文件 students.txt，写入三行内容：
   张三 90
   李四 85
   王五 92
  1. 再追加一行：
   赵六 88

参考答案：

# 写入前三行
with open("students.txt", "w", encoding="utf-8") as f:
    f.write("张三 90\n")
    f.write("李四 85\n")
    f.write("王五 92\n")

# 追加最后一行
with open("students.txt", "a", encoding="utf-8") as f:
    f.write("赵六 88\n")

练习 2：读取文件

题目：

  1. 读取 students.txt 的全部内容，并打印出来
  2. 读取文件的第一行，打印出来
  3. 将文件内容读成列表，每行作为一个元素，然后打印这个列表

参考答案：

python
# 读取全部内容
with open("students.txt", "r", encoding="utf-8") as f:
    content = f.read()
print("全部内容：")
print(content)

# 读取第一行
with open("students.txt", "r", encoding="utf-8") as f:
    first_line = f.readline()
print("第一行：", first_line.strip())

# 读取成列表
with open("students.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
print("列表形式：", [line.strip() for line in lines])

练习 3：字符串处理

题目：

  1. 去掉每行的空格和换行

  2. 拆分每行，得到名字和分数

  3. 将名字和分数分别存到两个列表，用 join() 拼接成如下输出：

   姓名列表: 张三 李四 王五 赵六
   分数列表: 90 85 92 88

参考答案：

python
names = []
scores = []

with open("students.txt", "r", encoding="utf-8") as f:
    for line in f:
        line = line.strip()        # 去掉换行
        name, score = line.split() # 拆分
        names.append(name)
        scores.append(score)

print("姓名列表:", " ".join(names))
print("分数列表:", " ".join(scores))

练习 4：小项目——计算平均分

题目：

  1. 读取 students.txt 中的分数

  2. 计算平均分

  3. 写入新文件 average.txt，内容如下：

   平均分: 88.75

参考答案：

python
# 读取分数
scores = []
with open("students.txt", "r", encoding="utf-8") as f:
    for line in f:
        score = int(line.strip().split()[1])  # 拿到分数并转成整数
        scores.append(score)

# 计算平均分
average = sum(scores) / len(scores)

# 写入新文件
with open("average.txt", "w", encoding="utf-8") as f:
    f.write(f"平均分: {average}")

四、f 对象里面都有些什么 ​

当我们使用 with ... open 语句打开一个文件的时候，系统就会给我们返回一个 文本文件对象，我们通过这个对象就可以来操作我们打开的文本，严格来说，f 是一个 TextIOWrapper 对象（文本文件对象），

它主要包含以下内容（可以用 dir(f) 查看）：

属性 / 方法说明
f.name文件名（如 "data.txt"）
f.mode打开模式（如 "r"、"w"、"a"）
f.encoding文件编码（如 "utf-8"）
f.closed文件是否已关闭（True / False）
f.read()读取整个文件内容
f.readline()读取一行
f.readlines()按行读取成列表
f.write()写入字符串
f.writelines()写入一个字符串列表
f.seek()移动光标位置
f.tell()查看当前光标位置
f.close()关闭文件
