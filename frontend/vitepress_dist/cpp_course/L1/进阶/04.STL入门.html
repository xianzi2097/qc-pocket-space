🧰 04. STL 入门 ​

在前面的学习中，我们已经使用过 string 和 vector——它们能处理字符串、动态存储数据，极大简化了编程工作。其中 vector 是 STL（Standard Template Library，标准模板库） 的核心容器之一，而 string 属于 C++ 标准库（虽然不属于原始 STL，但设计风格与 STL 容器高度一致）。

STL 三件套 ​

STL 由三个核心组件构成：

组件作用常见代表
容器存储数据vector、map、set、stack、queue
迭代器遍历容器中的元素begin()、end() 返回的就是迭代器
算法对数据进行操作sort、find、reverse、count

三者的关系：算法通过迭代器操作容器。

cpp
vector<int> v = {3, 1, 4, 1, 5};
//          ↑ 容器
sort(v.begin(), v.end());
//  ↑ 算法    ↑ 迭代器
1
2
3
4

算法不需要知道容器的具体实现细节，只要能通过迭代器访问元素就行。这就是 STL 的设计哲学：容器、迭代器、算法三者独立，通过迭代器连接。

本节先重点学习容器（pair、map、set、stack、queue），迭代器和算法在后续章节会逐步深入。

一、为什么需要 STL？ ​

在没有 STL 的情况下，很多常见操作需要自己从头实现：

需求不用 STL使用 STL
动态存储一组数据手动管理数组，处理扩容和内存释放vector<int> v; 自动管理
存储字符串并进行拼接、查找char 数组，手动处理 \0 结尾string s; 直接操作
存储键值对应关系（如学号→姓名）自己实现哈希表或链表map<int, string> m;
保证数据不重复每次插入前手动检查set<int> s; 自动去重
实现"后进先出"的逻辑自己写数组模拟栈stack<int> stk;

STL 的核心价值：用成熟的、经过验证的组件代替重复造轮子，把精力集中在解决实际问题上。

NOTE

STL 是 C++ 标准库的一部分，不需要安装额外的库。只需要包含对应的头文件即可使用。

三、迭代器 —— 遍历容器的工具 ​

3.1 什么是迭代器？ ​

在使用 vector 时，我们用下标 v[i] 访问元素，或者用范围 for 循环遍历。但 STL 中还有其他容器（如 map、set），它们不支持下标访问——不能用 m[0] 来遍历。

这时候就需要迭代器（iterator）。迭代器是一种"指向容器中某个位置"的对象，可以理解为一种通用的指针。

cpp
vector<int> v = {10, 20, 30};

// 迭代器就像一个"光标"，指向容器中的某个位置
auto it = v.begin();  // it 指向第一个元素（10）
cout << *it << endl;  // 10（解引用，取值）

it++;                 // 移动到下一个位置
cout << *it << endl;  // 20

3.2 begin() 和 end() ​

每个 STL 容器都提供两个成员函数来获取迭代器：

方法返回值含义
c.begin()指向第一个元素的迭代器遍历的起点
c.end()指向末尾之后的迭代器遍历的终点（不指向任何元素）
cpp
vector<int> v = {10, 20, 30};
//               ↑ begin()       ↑ end()

auto it = v.begin();  // 指向 10
it++;                 // 指向 20
it++;                 // 指向 30
it++;                 // 到达 end()，不再指向有效元素

NOTE

3.3 用迭代器遍历容器 ​

cpp
vector<int> v = {10, 20, 30, 40, 50};

// 传统迭代器写法
for (auto it = v.begin(); it != v.end(); it++) {
    cout << *it << " ";
}
cout << endl;

// 范围 for 循环（C++11）—— 本质就是迭代器的语法糖

    cout << x << " ";
}
cout << endl;

3.4 迭代器与算法的关系 ​

STL 算法通过迭代器操作容器，而不是直接操作容器本身：

cpp
vector<int> v = {5, 3, 1, 4, 2};

// sort 需要两个迭代器：起点和终点
sort(v.begin(), v.end());

// find 返回一个迭代器：指向找到的元素
auto it = find(v.begin(), v.end(), 4);
if (it != v.end()) {
    cout << "找到了：" << *it << endl;  // 4
}

// reverse 需要两个迭代器
reverse(v.begin(), v.end());

3.5 迭代器类型速览 ​

迭代器类型能力典型容器
输入迭代器只能向前读取istream_iterator
输出迭代器只能向前写入ostream_iterator
前向迭代器可向前移动，可读写forward_list、unordered_map
双向迭代器可向前和向后移动list、map、set
随机访问迭代器可任意跳转，像指针一样vector、deque、string

初学阶段只需要知道：vector 的迭代器能力最强（支持 it + 3、it - 2 这样的跳转），map/set 的迭代器支持前后移动（it++、it--），满足日常使用即可。

四、pair —— 一对值 ​

有时需要把两个值组合成一个整体。例如，一个学生的"姓名 + 成绩"，一个坐标的"x + y"。C++ 提供了 pair 来实现这一需求。

cpp
#include <iostream>
#include <utility>  // pair 的头文件（也可以通过 <map> 等间接引入）
using namespace std;

int main() {
    // 创建 pair
    pair<string, int> p1("Alice", 95);
    pair<int, int> p2 = {3, 7};  // C++11 初始化语法

    // 访问成员
    cout << "姓名：" << p1.first << endl;   // Alice
    cout << "成绩：" << p1.second << endl;  // 95

    cout << "x=" << p2.first << ", y=" << p2.second << endl;  // x=3, y=7

    // make_pair 快速创建
    auto p3 = make_pair("Bob", 88);
    cout << p3.first << " " << p3.second << endl;  // Bob 88

    return 0;
}

五、map —— 键值对应 ​

5.1 什么是 map？ ​

map 存储的是一组键值对（key-value pair），通过键（key）可以快速查找对应的值（value）。

生活中最常见的 map 就是字典：通过单词（键）查找释义（值）。

cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> scores;

    // 插入键值对
    scores["Alice"] = 95;
    scores["Bob"] = 88;
    scores["Charlie"] = 72;

    // 通过键查找值
    cout << "Alice 的成绩：" << scores["Alice"] << endl;   // 95
    cout << "Bob 的成绩：" << scores["Bob"] << endl;       // 88

    // 修改值
    scores["Alice"] = 98;

    // 判断键是否存在
    if (scores.find("David") == scores.end()) {
        cout << "David 没有成绩记录" << endl;
    }

    return 0;
}

5.2 map 的核心操作 ​

cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int, string> students;

    // 插入
    students[1001] = "Alice";
    students[1002] = "Bob";
    students.insert({1003, "Charlie"});

    // 遍历（map 按键自动排序）
    cout << "所有学生：" << endl;
    for (auto& [id, name] : students) {
        cout << "  学号 " << id << "：" << name << endl;
    }

    // 查找
    auto it = students.find(1002);
    if (it != students.end()) {
        cout << "找到学号1002：" << it->second << endl;
    }

    // 删除
    students.erase(1001);

    // 大小
    cout << "当前学生数：" << students.size() << endl;

    return 0;
}

5.3 map 常用操作速查表 ​

操作写法说明
定义map<string, int> m;键类型 string，值类型 int
插入/修改m["key"] = value;键不存在则插入，存在则修改
插入m.insert({k, v})键已存在时不插入
查找m.find(key)返回迭代器，到m.end() 表示不存在
判断键存在m.count(key)返回 1（存在）或 0（不存在）
删除m.erase(key)删除指定键的元素
大小m.size()当前元素个数
清空m.clear()清空所有元素

NOTE

map 的键（key）会自动排序（默认升序）。如果不需要排序，可以用 unordered_map，查找速度更快（O(1)），但不保证顺序。

5.4 应用示例：词频统计 ​

cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string word;
    map<string, int> freq;

    cout << "输入若干单词（以 end 结束）：" << endl;
    while (cin >> word && word != "end") {
        freq[word]++;  // 不存在时自动创建并设为0，然后+1
    }

    cout << "\n词频统计：" << endl;
    for (auto& [w, count] : freq) {
        cout << "  " << w << "：" << count << " 次" << endl;
    }

    return 0;
}

六、set —— 不重复的集合 ​

6.1 什么是 set？ ​

set 是一个不允许重复元素的容器，且元素会自动排序。

与 vector 的对比：

特性vectorset
允许重复是否
自动排序否是
插入效率尾部 O(1)O(log n)
查找效率O(n)O(log n)
cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;

    s.insert(30);
    s.insert(10);
    s.insert(20);
    s.insert(10);  // 重复，不会插入

    cout << "集合大小：" << s.size() << endl;  // 3（不是4）

    for (int x : s) {
        cout << x << " ";  // 输出：10 20 30（自动排序）
    }
    cout << endl;

    return 0;
}

七、stack —— 后进先出 ​

7.1 什么是 stack？ ​

stack（栈）是一种后进先出（LIFO） 的数据结构。想象一摞盘子——最后放上去的盘子，最先被拿下来。

放入顺序：1 → 2 → 3
取出顺序：3 → 2 → 1（后进先出）
1
2

7.2 基本操作 ​

cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    stack<int> stk;

    stk.push(10);   // 压栈（放入）
    stk.push(20);
    stk.push(30);

    cout << "栈顶：" << stk.top() << endl;  // 30（最后放入的）
    cout << "栈大小：" << stk.size() << endl; // 3

    stk.pop();       // 弹栈（取出栈顶）
    cout << "弹出后栈顶：" << stk.top() << endl;  // 20

    stk.pop();
    stk.pop();

    cout << "是否为空：" << stk.empty() << endl;  // 1（true）

    return 0;
}

7.3 stack 常用操作速查表 ​

操作写法说明
定义stack<int> stk;存储 int 类型的栈
压栈stk.push(x)将 x 放入栈顶
弹栈stk.pop()移除栈顶元素（无返回值）
查看栈顶stk.top()返回栈顶元素
大小stk.size()当前元素个数
判空stk.empty()空返回 true

NOTE

stack 只能访问栈顶元素，不能随机访问中间的元素。这是由其 LIFO 特性决定的——栈的设计就是为了限制访问顺序。

7.4 应用示例：括号匹配 ​

判断一个字符串中的括号是否匹配（()、[]、{} 成对出现）：

cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    stack<char> stk;
    bool valid = true;

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);  // 左括号压栈
        } else if (c == ')' || c == ']' || c == '}') {
            if (stk.empty()) {
                valid = false;  // 没有匹配的左括号
                break;
            }
            char top = stk.top();
            stk.pop();
            // 检查是否匹配
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                valid = false;
                break;
            }
        }
    }

    if (!stk.empty()) valid = false;  // 栈中还有未匹配的左括号

    cout << (valid ? "匹配" : "不匹配") << endl;
    return 0;
}

八、queue —— 先进先出 ​

8.1 什么是 queue？ ​

queue（队列）是一种先进先出（FIFO） 的数据结构。就像排队买票——先来的人先服务。

进入顺序：A → B → C
离开顺序：A → B → C（先进先出）
1
2

8.2 基本操作 ​

cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> q;

    q.push("Alice");    // 入队
    q.push("Bob");
    q.push("Charlie");

    cout << "队首：" << q.front() << endl;  // Alice（最先入队的）
    cout << "队尾：" << q.back() << endl;   // Charlie（最后入队的）
    cout << "队列大小：" << q.size() << endl; // 3

    q.pop();  // 出队（移除队首）
    cout << "出队后队首：" << q.front() << endl;  // Bob

    return 0;
}

操作写法说明

#include <iostream>

                cout << line.front() << " 请到窗口办理" << endl;
                line.pop();
            }
        } else {
            break;
        }
    }
    return 0;
}

十、容器选择指南 ​

面对具体问题时，如何选择合适的容器？

需求推荐容器理由
按顺序存储，需要随机访问vector下标访问 O(1)
存储键值对应关系map通过键快速查找值，O(log n)
保证数据不重复set自动去重，O(log n)
需要后进先出stack只操作栈顶
需要先进先出queue只操作队首和队尾
频繁在中间插入/删除list链表结构，插入删除 O(1)

TIP

初学阶段，vector、map、set 三个容器能覆盖绝大多数场景。stack 和 queue 在算法题中出现频率也很高，建议熟练掌握。

十一、小结 ​

  • STL 是 C++ 标准库提供的工具箱，包含容器、算法和迭代器。
  • string 和 vector 我们已经会了——它们都是 STL 容器。
  • pair 将两个值组合成一个整体，是 map 的基础。
  • map 存储键值对，通过键快速查找值，自动按键排序。
  • set 存储不重复的元素，自动排序。
  • stack 是后进先出的栈，queue 是先进先出的队列。
  • STL 容器的接口具有一致性：.size()、.empty()、.clear() 是通用的。
  • 学会选择合适的容器，是使用 STL 的关键。

十二、练习 ​

  1. 输入 n 个整数，用 map 统计每个数字出现的次数，并输出出现次数最多的数字及其出现次数。
  2. 输入一行文本，用 set 存储所有出现过的字母（不区分大小写），输出集合中的字母个数。
  3. 输入 n 个整数，用 set 去重后，输出第二小的数（提示：set 自动排序，可以用迭代器访问）。
  4. 使用 stack 判断一个字符串中的括号是否匹配。要求支持 ()、[]、{} 三种括号。
  5. 输入若干个字符串（以 end 结束），用 queue 实现排队顺序，模拟叫号系统：每次叫出队首的人，直到队列为空。
  6. 用 map 实现一个简单的通讯录：支持添加联系人（姓名→电话）、查找联系人、删除联系人。
  7. 思考题：vector、set、map 都有 .find() 方法，它们的返回值有什么共同点？查找失败时如何判断？
