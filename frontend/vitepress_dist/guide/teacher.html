👨‍🏫 教师使用指南 ​

二、详细说明 ​

1. 启动服务 ​

  1. 打开 QC 启动器（桌面上的程序）
  2. 选择模式：
    • 本地模式 — 教室局域网使用（自动检测本机 IP）
    • 域名模式 — 外网访问（需要配置域名）
  3. 点击 「启动服务」 按钮
  4. 等待状态变为 🟢 绿色，弹窗会显示访问地址

提示：启动后不要关闭启动器窗口，最小化即可。

2. 登录后台 ​

  1. 在浏览器中打开启动器显示的地址
  2. 点击 「登录」
  3. 使用管理员或老师账号登录
    • 默认管理员：admin / 111111
    • 测试老师：林老师(t) / 111111

3. 数据看板 ​

登录后默认进入数据看板，可以查看：

  • 学生总数 — 所有班级的学生人数
  • 班级数量 — 你创建的班级数
  • 后端状态 — 服务是否正常运行

4. 班级管理 ​

  1. 点击左侧导航 「学生管理」
  2. 点击 「新建班级」，输入班级名称、设置上课时间
  3. 班级列表支持：
    • 改名 — 修改班级名称（课堂记录会同步改名）
    • 删除 — 移入回收站，可恢复

5. 学生管理 ​

查看班级和学生 ​

  1. 点击 「学生管理」
  2. 左侧显示班级列表，点击班级查看学生
  3. 点击学生 「详情」 查看该生的课堂记录

添加学生 ​

在班级页面点击 「添加学生」，输入学生姓名即可自动创建账号。

移除学生 ​

在班级学生列表中移除学生（不删除学生账号）。

跨班学生 ​

如果一个学生被多个老师教过，查看详情时会显示全部老师的课堂记录，其他老师的记录会标注 （老师名）。

6. 课堂记录 ​

每节课后记录学生的出勤和学习情况：

  1. 点击 「课堂记录」
  2. 选择班级，点击 「新建记录」
  3. 填写日期，逐一点击学生标注：
    • ✅ 出勤 — 正常上课
    • ❌ 缺勤 — 未到（可填备注原因）
  4. 填写本节课的学习内容
  5. 点击保存

记录按月归档，可以随时查看历史记录。

7. 课件管理 ​

创建课程 ​

  1. 点击 「课件管理」
  2. 点击 「创建课程」，输入课程名称和类型
  3. 创建后在课程下添加课件文件夹

上传素材 ​

  1. 点击课程进入详情
  2. 点击 「上传课件」
  3. 选择课件文件夹名称
  4. 上传 main.sb3（教师演示版）和 student.sb3（学生练习版）

8. 发送消息 ​

  1. 点击 「发送消息」
  2. 选择收件人（支持按班级筛选）
  3. 填写主题和内容（支持 Markdown 格式）
  4. 点击发送

学生登录后在个人中心可以看到消息。

三、常见问题 ​

Q：学生无法访问怎么办？ A：检查学生设备和老师是否在同一个网络，尝试用手机热点测试。

Q：如何重置学生密码？ A：联系管理员在后台重置。

Q：如何添加新老师？ A：使用管理员账号登录，在用户管理中添加。

Q：服务启动了但浏览器打不开？ A：检查防火墙是否拦截了端口（默认 80 和 8000），尝试以管理员身份运行启动器。
