CSV 文件操作 ​

一、CSV 文件 ​

1.CSV 是什么 ​

CSV（Comma-Separated Values），中文叫“逗号分隔值文件”。 它是一种纯文本格式的文件，用来存储表格数据。

📂 举个例子： 假设我们有一张学生成绩表：

姓名年龄成绩
小明1295
小红1388
小刚1292

保存成 CSV 后，里面的内容 r 如下：

姓名,年龄,成绩
小明,12,95
小红,13,88
小刚,12,92

每一行代表一条记录（一个学生），每个字段之间用 逗号 , 来分隔。

2. CSV 的结构特点 ​

特征说明
文件类型纯文本文件（可以用记事本打开）
后缀名.csv
分隔符默认用 逗号（也可能是 ; 或 \t）
编码一般是 UTF-8 或 GBK
结构一行表示一条记录，字段按顺序排列
可读性人和程序都能轻松读取

3. 常见问题与陷阱 ​

  1. 如果一个数据出现了分割符，为了避免被解析成2个列，需要用双引号包起来。
   "王小明, Jr.",13,89
1

🤣由于双引号被用来包裹数据，所以如果数据里面出现双引号，需要用连续的两个双引号来表示一个引号，以此类推，两个双引号则需要四个。

  1. 不同地区的分隔符可能不一样有的用 ,有的用 ;有的用制表符（\t），所以 Python 读的时候说明分隔符是比较保险的做法。

  2. 不同系统换行符不一样：

    • Windows 用 \r\n

    • macOS / Linux 用 \n

二、在 Python 中操作 CSV 文件 ​

CSV 文件本质上就是一种 遵守特定格式约定的文本文件（txt）。 我们当然可以使用普通的文件读写函数（如 open()、read()、write()）来手动操作 CSV，然后再编写代码对每一行进行分割与解析。 像 CSV 这样常见且格式固定的数据文件类型，Python 官方已经为我们准备好了专门的工具库 —— csv 模块。 通过使用 csv 库，我们可以轻松实现对 CSV 文件的读取、写入、筛选与格式化输出，而不必自己去处理各种逗号、引号和换行符的细节问题。

通过使用 csv 库，我们可以轻松实现：

  • 读取与写入 CSV 文件；
  • 自动处理分隔符、引号、换行符；
  • 以“列表”或“字典”形式操作每一行数据。

Python 的 csv 模块提供了两种主要的读取方式：

  • csv.reader：按行读取，每一行返回一个列表；
  • csv.DictReader：按“字段名”读取，每一行返回一个字典。

1. csv.reader 读取文件 ​

使用 csv.reader 是最基础、最常用的读取方法：

python
import csv

with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)   # 创建读取对象
    for row in reader:
        print(row)

2. csv.DictReader 读取文件 ​

csv.DictReader 和 csv.reader 都是读取数据，只不过 csv.reader 返回的是一个"列表"，而 csv.DictReader 返回的是一个"字典"，键是它的列名：

python
import csv

# 假设 CSV 文件名是 data.csv
with open("demo.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f,delimiter = ',')  # 默认逗号分隔，可以改 delimiter=';' 等
    for row in reader:
        print(row)  # row 是一个字典，键是表头，值是对应的数据

示例：计算学生的数学平均分：

python
import csv

def calculate_math_average(filename):
    total_score = 0
    count = 0
    with open(filename, 'r', encoding='utf-8', newline='') as file:
        reader = csv.DictReader(file)
        for row in reader:
            # ✨注意：从CSV读取的数据默认是字符串，需要转换为整数
            total_score += int(row['数学'])
            count += 1
    return total_score / count if count > 0 else 0

average = calculate_math_average('demo.csv')
print(f"数学平均分: {average:.2f}")

NOTE

惰性迭代器指的是： 不会一次性把所有数据读进内存，而是等你要一个，才生成一个的数据结构。csv.reader() / DictReader()返回的都是惰性迭代器，所以都可以使用 next()来跳过一行。

python
import csv

with open("demo.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    
    # 跳过第一行表头
    next(reader)
    
    # 遍历数据行
    for row in reader:
        print(row)

3 . csv.write() 写入数据 ​

TIP

writer.writerow() 只接受一个参数，而且这个参数必须是一个序列（列表、元组等）

newline='' 是为了避免 Windows 写 CSV 时产生多余空行，让 CSV 模块自己控制换行。

- 单行写入 writerow() ​
python
import csv

# 写入单行数据
with open('student.csv', 'w', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['姓名', '成绩', '班级'])  # 表头
    writer.writerow(['张三', 90, '1班'])       # 数据行
    writer.writerow(['李四', 85, '2班'])       # 数据行
