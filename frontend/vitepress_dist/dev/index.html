二次开发 ​

写给要改 CodeNova 的人。只给地图，细节按图索骥。

四个仓库 ​

仓库内容
qc-pocket-space主体：FastAPI 后端 + React 前端产物 + 运行时 + 文档（发行版，唯一版本锚）
qc-launcher控制面板：启停服务、注册账号、自动备份
qc-frontendReact 前端源码（Vite + TypeScript + Tailwind，主开发分支 UI）
scratch-TeachingScratch 4.0-QC 魔改版源码

本地跑起来 ​

  • 后端：backend_v2 下 .venv\Scripts\python -m uvicorn main:app --port 8001
  • 前端：qx-dashboard-ts 下 npm run dev（5173）
  • 日常不敲命令：控制面板点 🟢

测试与纪律 ​

  • 后端全量：backend_v2 下 python -m pytest（236 条），pre-push 强制跑
  • 开发顺序：规范行 → 测试先红 → 实现变绿（改接口先改 backend-v2-api-spec.md）
  • 源码与 build 产物分开提交；已推送的提交不 amend、不 force push
