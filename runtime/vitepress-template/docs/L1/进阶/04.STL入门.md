# 04. STL 入门

在前面的学习中，我们已经使用过 `string` 和 `vector`——它们能处理字符串、动态存储数据，极大简化了编程工作。其中 `vector` 是 **STL（Standard Template Library，标准模板库）** 的核心容器之一，而 `string` 属于 C++ 标准库（虽然不属于原始 STL，但设计风格与 STL 容器高度一致）。

## 1. STL 三件套

STL 由三个核心组件构成：

| 组件             | 作用             | 常见代表                                           |
| ---------------- | ---------------- | -------------------------------------------------- |
| **容器**   | 存储数据         | `vector`、`map`、`set`、`stack`、`queue` |
| **迭代器** | 遍历容器中的元素 | `begin()`、`end()` 返回的就是迭代器            |
| **算法**   | 对数据进行操作   | `sort`、`find`、`reverse`、`count`         |

三者的关系：**算法通过迭代器操作容器**。

```cpp
vector<int> v = {3, 1, 4, 1, 5};
//          ↑ 容器
sort(v.begin(), v.end());
//  ↑ 算法    ↑ 迭代器
```

算法不需要知道容器的具体实现细节，只要能通过迭代器访问元素就行。这就是 STL 的设计哲学：**容器、迭代器、算法三者独立，通过迭代器连接**。

本节先重点学习**容器**（pair、map、set、stack、queue），迭代器和算法在后续章节会逐步深入。

## 2. 为什么需要 STL？

在没有 STL 的情况下，很多常见操作需要自己从头实现：

| 需求                             | 不用 STL                            | 使用 STL                    |
| -------------------------------- | ----------------------------------- | --------------------------- |
| 动态存储一组数据                 | 手动管理数组，处理扩容和内存释放    | `vector<int> v;` 自动管理 |
| 存储字符串并进行拼接、查找       | `char` 数组，手动处理 `\0` 结尾 | `string s;` 直接操作      |
| 存储键值对应关系（如学号→姓名） | 自己实现哈希表或链表                | `map<int, string> m;`     |
| 保证数据不重复                   | 每次插入前手动检查                  | `set<int> s;` 自动去重    |
| 实现“后进先出”的逻辑             | 自己写数组模拟栈                    | `stack<int> stk;`         |

STL 的核心价值：**用成熟的、经过验证的组件代替重复造轮子**，把精力集中在解决实际问题上。

::: info 注意
STL 是 C++ 标准库的一部分，不需要安装额外的库。只需要包含对应的头文件即可使用。
:::

## 3. 我们已经会的 STL

### 3.1 string —— 字符串

回顾一下我们已经掌握的 `string` 操作：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Hello";
    s += " C++";              // 拼接
    cout << s.length() << endl;  // 长度：9
    cout << s.find("C++") << endl; // 查找：6

    string sub = s.substr(0, 5);  // 截取子串
    cout << sub << endl;          // Hello
    return 0;
}
```

`string` 本质上是一个**类模板的特化**（`basic_string<char>`），它把字符数组的管理封装成了简洁的接口。我们调用 `.length()`、`.find()` 时，实际上是在调用 `string` 对象的成员函数。

### 3.2 vector —— 动态数组

回顾 `vector` 的核心用法：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};
    v.push_back(40);           // 添加元素
    cout << v.size() << endl;  // 长度：4

    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

`vector` 是一个**类模板**——`vector<int>` 表示存储 `int` 的动态数组，`vector<string>` 表示存储 `string` 的动态数组。尖括号 `<>` 中的类型参数决定了容器存放的数据类型。

::: tip 提示
`string` 和 `vector` 的接口设计有共同的规律：`.size()` 获取长度、`.empty()` 判断是否为空、`.clear()` 清空内容。这种**接口一致性**是 STL 的重要设计原则——学会一个容器，其他的就容易上手。
:::

## 4. 迭代器 —— 遍历容器的工具

### 4.1 什么是迭代器？

在使用 `vector` 时，我们用下标 `v[i]` 访问元素，或者用范围 for 循环遍历。但 STL 中还有其他容器（如 `map`、`set`），它们**不能用下标按位置遍历**——`set` 根本没有下标运算符；而 `map` 的 `m[0]` 是按**键**查找键为 `0` 的元素（不存在还会插入），并不是「第 0 个元素」。

这时候就需要**迭代器（iterator）**。迭代器是一种“指向容器中某个位置”的对象，可以理解为一种**通用的指针**。

```cpp
vector<int> v = {10, 20, 30};

// 迭代器就像一个"光标"，指向容器中的某个位置
auto it = v.begin();  // it 指向第一个元素（10）
cout << *it << endl;  // 10（解引用，取值）

it++;                 // 移动到下一个位置
cout << *it << endl;  // 20
```

### 4.2 begin() 和 end()

每个 STL 容器都提供两个成员函数来获取迭代器：

| 方法          | 返回值                           | 含义                         |
| ------------- | -------------------------------- | ---------------------------- |
| `c.begin()` | 指向**第一个元素**的迭代器 | 遍历的起点                   |
| `c.end()`   | 指向**末尾之后**的迭代器   | 遍历的终点（不指向任何元素） |

```cpp
vector<int> v = {10, 20, 30};
//               ↑ begin()       ↑ end()

auto it = v.begin();  // 指向 10
it++;                 // 指向 20
it++;                 // 指向 30
it++;                 // 到达 end()，不再指向有效元素
```

::: info 注意
`end()` 返回的不是最后一个元素，而是**最后一个元素之后的位置**。这是 C++ STL 的统一约定——类似于数组越界一个位置。判断遍历结束的条件是 `it == c.end()`。
:::

### 4.3 用迭代器遍历容器

**遍历 vector：**

```cpp
vector<int> v = {10, 20, 30, 40, 50};

// 传统迭代器写法
for (auto it = v.begin(); it != v.end(); it++) {
    cout << *it << " ";
}
cout << endl;

// 范围 for 循环（C++11）—— 本质就是迭代器的语法糖
for (int x : v) {
    cout << x << " ";
}
cout << endl;
```

两种写法输出完全相同。范围 for 循环是编译器帮你简化后的写法，底层仍然使用迭代器。

**遍历 map：**

```cpp
map<string, int> m = {{"Alice", 95}, {"Bob", 88}};

// map 不支持下标遍历，必须用迭代器
for (auto it = m.begin(); it != m.end(); it++) {
    cout << it->first << "：" << it->second << endl;
}
// 输出：
// Alice：95
// Bob：88
```

注意 map 遍历时用的是 `it->first` 和 `it->second`（箭头运算符），因为迭代器指向的是一个 `pair` 对象。

### 4.4 迭代器与算法的关系

STL 算法通过迭代器操作容器，而不是直接操作容器本身：

```cpp
vector<int> v = {5, 3, 1, 4, 2};

// sort 需要两个迭代器：起点和终点
sort(v.begin(), v.end());

// find 返回一个迭代器：指向找到的元素
auto it = find(v.begin(), v.end(), 4);
if (it != v.end()) {
    cout << "找到了：" << *it << endl;  // 4
}

// reverse 需要两个迭代器
reverse(v.begin(), v.end());
```

这就是 STL 的设计思想：**算法不需要知道容器是 vector 还是 deque，只要能通过迭代器访问元素就行**。同一个 `sort` 算法可以对不同类型的容器排序，只要容器提供了合适的迭代器。

### 4.5 迭代器类型速览

| 迭代器类型               | 能力                   | 典型容器                            |
| ------------------------ | ---------------------- | ----------------------------------- |
| 输入迭代器               | 只能向前读取           | `istream_iterator`                |
| 输出迭代器               | 只能向前写入           | `ostream_iterator`                |
| **前向迭代器**     | 可向前移动，可读写     | `forward_list`、`unordered_map` |
| **双向迭代器**     | 可向前和向后移动       | `list`、`map`、`set`          |
| **随机访问迭代器** | 可任意跳转，像指针一样 | `vector`、`deque`、`string`   |

初学阶段只需要知道：**vector 的迭代器能力最强**（支持 `it + 3`、`it - 2` 这样的跳转），**map/set 的迭代器支持前后移动**（`it++`、`it--`），满足日常使用即可。

## 5. pair —— 一对值

有时需要把两个值组合成一个整体。例如，一个学生的“姓名 + 成绩”，一个坐标的“x + y”。C++ 提供了 `pair` 来实现这一需求。

```cpp
#include <iostream>
#include <utility>  // pair 的头文件（也可以通过 <map> 等间接引入）
using namespace std;

int main() {
    // 创建 pair
    pair<string, int> p1("Alice", 95);
    pair<int, int> p2 = {3, 7};  // C++11 初始化语法

    // 访问成员
    cout << "姓名：" << p1.first << endl;   // Alice
    cout << "成绩：" << p1.second << endl;  // 95

    cout << "x=" << p2.first << ", y=" << p2.second << endl;  // x=3, y=7

    // make_pair 快速创建
    auto p3 = make_pair("Bob", 88);
    cout << p3.first << " " << p3.second << endl;  // Bob 88

    return 0;
}
```

`pair` 的两个成员分别叫 `.first` 和 `.second`。类型可以不同，如 `pair<string, int>`。

::: info 注意
`pair` 是很多 STL 容器的基础构件——`map` 中的每个元素就是一个 `pair`（键 + 值）。掌握 `pair`，学习 `map` 会更加顺畅。
:::

### 5.1 pair 的常见用法

| 操作       | 写法                      | 说明                              |
| ---------- | ------------------------- | --------------------------------- |
| 定义       | `pair<int, string> p;`  | 第一个元素类型 int，第二个 string |
| 赋值       | `p = {1, "hello"};`     | C++11 起可直接用花括号            |
| 访问第一个 | `p.first`               | 返回键（key）                     |
| 访问第二个 | `p.second`              | 返回值（value）                   |
| 快速创建   | `make_pair(1, "hello")` | 自动推导类型                      |

## 6. map —— 键值对应

### 6.1 什么是 map？

`map` 存储的是一组**键值对（key-value pair）**，通过键（key）可以快速查找对应的值（value）。

生活中最常见的 map 就是**字典**：通过单词（键）查找释义（值）。

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> scores;

    // 插入键值对
    scores["Alice"] = 95;
    scores["Bob"] = 88;
    scores["Charlie"] = 72;

    // 通过键查找值
    cout << "Alice 的成绩：" << scores["Alice"] << endl;   // 95
    cout << "Bob 的成绩：" << scores["Bob"] << endl;       // 88

    // 修改值
    scores["Alice"] = 98;

    // 判断键是否存在
    if (scores.find("David") == scores.end()) {
        cout << "David 没有成绩记录" << endl;
    }

    return 0;
}
```

### 6.2 map 的核心操作

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int, string> students;

    // 插入
    students[1001] = "Alice";
    students[1002] = "Bob";
    students.insert({1003, "Charlie"});

    // 遍历（map 按键自动排序）
    cout << "所有学生：" << endl;
    for (auto& [id, name] : students) {
        cout << "  学号 " << id << "：" << name << endl;
    }

    // 查找
    auto it = students.find(1002);
    if (it != students.end()) {
        cout << "找到学号1002：" << it->second << endl;
    }

    // 删除
    students.erase(1001);

    // 大小
    cout << "当前学生数：" << students.size() << endl;

    return 0;
}
```

输出：

```text
所有学生：
  学号 1001：Alice
  学号 1002：Bob
  学号 1003：Charlie
找到学号1002：Bob
当前学生数：2
```

::: tip 提示
`map` 中的 `auto& [id, name]` 是 C++17 的**结构化绑定**语法，可以直接给 `pair` 的 `.first` 和 `.second` 起名字，比 `it->first`、`it->second` 更直观。如果编译器版本较低，也可以用传统写法：

```cpp
for (auto it = students.begin(); it != students.end(); it++) {
    cout << it->first << "：" << it->second << endl;
}
```
:::

### 6.3 map 常用操作速查表

| 操作       | 写法                    | 说明                                 |
| ---------- | ----------------------- | ------------------------------------ |
| 定义       | `map<string, int> m;` | 键类型 string，值类型 int            |
| 插入/修改  | `m["key"] = value;`   | 键不存在则插入，存在则修改           |
| 插入       | `m.insert({k, v})`    | 键已存在时不插入                     |
| 查找       | `m.find(key)`         | 返回迭代器，到`m.end()` 表示不存在 |
| 判断键存在 | `m.count(key)`        | 返回 1（存在）或 0（不存在）         |
| 删除       | `m.erase(key)`        | 删除指定键的元素                     |
| 大小       | `m.size()`            | 当前元素个数                         |
| 清空       | `m.clear()`           | 清空所有元素                         |

::: info 注意
`map` 的键（key）会**自动排序**（默认升序）。如果不需要排序，可以用 `unordered_map`，查找速度更快（O(1)），但不保证顺序。
:::

### 6.4 应用示例：词频统计

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string word;
    map<string, int> freq;

    cout << "输入若干单词（以 end 结束）：" << endl;
    while (cin >> word && word != "end") {
        freq[word]++;  // 不存在时自动创建并设为0，然后+1
    }

    cout << "\n词频统计：" << endl;
    for (auto& [w, count] : freq) {
        cout << "  " << w << "：" << count << " 次" << endl;
    }

    return 0;
}
```

运行示例：

```text
输入若干单词（以 end 结束）：
apple banana apple cherry apple banana end

词频统计：
  apple：3 次
  banana：2 次
  cherry：1 次
```

`freq[word]++` 是 `map` 最常用的技巧之一：如果 `word` 不存在，`map` 会自动创建该键并将其值初始化为 0，然后再执行 `++`。

## 7. set —— 不重复的集合

### 7.1 什么是 set？

`set` 是一个**不允许重复元素**的容器，且元素会**自动排序**。

与 `vector` 的对比：

| 特性     | `vector` | `set`  |
| -------- | ---------- | -------- |
| 允许重复 | 是         | 否       |
| 自动排序 | 否         | 是       |
| 插入效率 | 尾部 O(1)  | O(log n) |
| 查找效率 | O(n)       | O(log n) |

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;

    s.insert(30);
    s.insert(10);
    s.insert(20);
    s.insert(10);  // 重复，不会插入

    cout << "集合大小：" << s.size() << endl;  // 3（不是4）

    for (int x : s) {
        cout << x << " ";  // 输出：10 20 30（自动排序）
    }
    cout << endl;

    return 0;
}
```

### 7.2 set 常用操作速查表

| 操作     | 写法            | 说明                               |
| -------- | --------------- | ---------------------------------- |
| 定义     | `set<int> s;` | 存储 int 类型的集合                |
| 插入     | `s.insert(x)` | 插入元素，重复则忽略               |
| 查找     | `s.find(x)`   | 返回迭代器，`s.end()` 表示不存在 |
| 判断存在 | `s.count(x)`  | 返回 1（存在）或 0（不存在）       |
| 删除     | `s.erase(x)`  | 删除指定元素                       |
| 大小     | `s.size()`    | 当前元素个数                       |
| 清空     | `s.clear()`   | 清空所有元素                       |

### 7.3 应用示例：去重

输入 n 个整数，输出去重并排序后的结果：

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);  // 自动去重
    }

    for (int x : s) {
        cout << x << " ";  // 自动升序
    }
    cout << endl;

    return 0;
}
```

::: tip 提示
如果只需要去重而不需要排序，`set` 和 `vector` 配合使用也是一种选择：先把数据存入 `set` 去重，再复制回 `vector` 进行后续操作。
:::

## 8. stack —— 后进先出

### 8.1 什么是 stack？

`stack`（栈）是一种**后进先出（LIFO）** 的数据结构。想象一摞盘子——最后放上去的盘子，最先被拿下来。

```text
放入顺序：1 → 2 → 3
取出顺序：3 → 2 → 1（后进先出）
```

### 8.2 基本操作

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    stack<int> stk;

    stk.push(10);   // 压栈（放入）
    stk.push(20);
    stk.push(30);

    cout << "栈顶：" << stk.top() << endl;  // 30（最后放入的）
    cout << "栈大小：" << stk.size() << endl; // 3

    stk.pop();       // 弹栈（取出栈顶）
    cout << "弹出后栈顶：" << stk.top() << endl;  // 20

    stk.pop();
    stk.pop();

    cout << "是否为空：" << stk.empty() << endl;  // 1（true）

    return 0;
}
```

### 8.3 stack 常用操作速查表

| 操作     | 写法                | 说明                     |
| -------- | ------------------- | ------------------------ |
| 定义     | `stack<int> stk;` | 存储 int 类型的栈        |
| 压栈     | `stk.push(x)`     | 将 x 放入栈顶            |
| 弹栈     | `stk.pop()`       | 移除栈顶元素（无返回值） |
| 查看栈顶 | `stk.top()`       | 返回栈顶元素             |
| 大小     | `stk.size()`      | 当前元素个数             |
| 判空     | `stk.empty()`     | 空返回 true              |

::: info 注意
`stack` 只能访问栈顶元素，不能随机访问中间的元素。这是由其 LIFO 特性决定的——栈的设计就是为了限制访问顺序。
:::

### 8.4 应用示例：括号匹配

判断一个字符串中的括号是否匹配（`()`、`[]`、`{}` 成对出现）：

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    stack<char> stk;
    bool valid = true;

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);  // 左括号压栈
        } else if (c == ')' || c == ']' || c == '}') {
            if (stk.empty()) {
                valid = false;  // 没有匹配的左括号
                break;
            }
            char top = stk.top();
            stk.pop();
            // 检查是否匹配
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                valid = false;
                break;
            }
        }
    }

    if (!stk.empty()) valid = false;  // 栈中还有未匹配的左括号

    cout << (valid ? "匹配" : "不匹配") << endl;
    return 0;
}
```

## 9. queue —— 先进先出

### 9.1 什么是 queue？

`queue`（队列）是一种**先进先出（FIFO）** 的数据结构。就像排队买票——先来的人先服务。

```text
进入顺序：A → B → C
离开顺序：A → B → C（先进先出）
```

### 9.2 基本操作

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> q;

    q.push("Alice");    // 入队
    q.push("Bob");
    q.push("Charlie");

    cout << "队首：" << q.front() << endl;  // Alice（最先入队的）
    cout << "队尾：" << q.back() << endl;   // Charlie（最后入队的）
    cout << "队列大小：" << q.size() << endl; // 3

    q.pop();  // 出队（移除队首）
    cout << "出队后队首：" << q.front() << endl;  // Bob

    return 0;
}
```

### 9.3 queue 常用操作速查表

| 操作     | 写法              | 说明                     |
| -------- | ----------------- | ------------------------ |
| 定义     | `queue<int> q;` | 存储 int 类型的队列      |
| 入队     | `q.push(x)`     | 将 x 放入队尾            |
| 出队     | `q.pop()`       | 移除队首元素（无返回值） |
| 查看队首 | `q.front()`     | 返回队首元素             |
| 查看队尾 | `q.back()`      | 返回队尾元素             |
| 大小     | `q.size()`      | 当前元素个数             |
| 判空     | `q.empty()`     | 空返回 true              |

### 9.4 应用示例：排队叫号

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> line;
    int choice;

    while (true) {
        cout << "\n1.取号  2.叫号  3.退出\n选择：";
        cin >> choice;

        if (choice == 1) {
            string name;
            cout << "请输入姓名：";
            cin >> name;
            line.push(name);
            cout << name << " 已取号，当前排队 " << line.size() << " 人" << endl;
        } else if (choice == 2) {
            if (line.empty()) {
                cout << "当前无人排队" << endl;
            } else {
                cout << line.front() << " 请到窗口办理" << endl;
                line.pop();
            }
        } else {
            break;
        }
    }
    return 0;
}
```

::: info 注意
`queue` 同样只能访问队首和队尾，不能随机访问。在算法中，`queue` 是实现 **BFS（广度优先搜索）** 的核心工具。
:::

## 10. 看懂题解中的 STL

在阅读算法题解时，经常会看到 STL 的使用。以下是一些典型场景：

### 场景一：用 map 统计出现次数

```cpp
// 题目：统计每个数字出现的次数
map<int, int> cnt;
for (int x : nums) {
    cnt[x]++;
}
```

### 场景二：用 set 快速判重

```cpp
// 题目：判断数组中是否有重复元素
set<int> s(arr.begin(), arr.end());
if (s.size() < n) {
    cout << "有重复" << endl;
}
```

### 场景三：用 stack 处理嵌套结构

```cpp
// 题目：计算嵌套括号的最大深度
stack<char> stk;
int maxDepth = 0;
for (char c : s) {
    if (c == '(') {
        stk.push(c);
        maxDepth = max(maxDepth, (int)stk.size());
    } else if (c == ')') {
        stk.pop();
    }
}
```

### 场景四：用 queue 实现 BFS

```cpp
// 题目：从起点出发，每次可以走一步，求最短路径
queue<int> q;
q.push(start);
visited[start] = true;

while (!q.empty()) {
    int cur = q.front();
    q.pop();
    // 检查 cur 的所有邻居，未访问的入队
}
```

## 11. 容器选择指南

面对具体问题时，如何选择合适的容器？

| 需求                     | 推荐容器   | 理由                       |
| ------------------------ | ---------- | -------------------------- |
| 按顺序存储，需要随机访问 | `vector` | 下标访问 O(1)              |
| 存储键值对应关系         | `map`    | 通过键快速查找值，O(log n) |
| 保证数据不重复           | `set`    | 自动去重，O(log n)         |
| 需要后进先出             | `stack`  | 只操作栈顶                 |
| 需要先进先出             | `queue`  | 只操作队首和队尾           |
| 频繁在中间插入/删除      | `list`   | 链表结构，插入删除 O(1)    |

::: tip 提示
初学阶段，`vector`、`map`、`set` 三个容器能覆盖绝大多数场景。`stack` 和 `queue` 在算法题中出现频率也很高，建议熟练掌握。
:::

## 12. 小结

- **STL** 是 C++ 标准库提供的工具箱，包含容器、算法和迭代器。
- **`string`** 和 **`vector`** 我们已经会了——它们都是 STL 容器。
- **`pair`** 将两个值组合成一个整体，是 `map` 的基础。
- **`map`** 存储键值对，通过键快速查找值，自动按键排序。
- **`set`** 存储不重复的元素，自动排序。
- **`stack`** 是后进先出的栈，**`queue`** 是先进先出的队列。
- STL 容器的接口具有**一致性**：`.size()`、`.empty()`、`.clear()` 是通用的。
- 学会选择合适的容器，是使用 STL 的关键。
